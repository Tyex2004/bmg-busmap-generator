## class Node（道路节点，从 JSON 加载）

道路节点是分布在平面空间的点，是此生成器一切几何空间参考的基础。

### `JsonProperty` 属性列表

| 属性名 | 类型     | 说明         |
| --- |--------|------------|
| Id | int | 道路节点 ID      |
| Name | string | 道路节点名称       |
| JSONCoord | decimal[2] | JSON 坐标 |

### `JSONIgnore` 属性列表（后期计算）

| 属性名 | 类型     | 说明         |
| --- |--------|------------|
| StraightRoads | StraightRoad[4] | 该道路节点所在直线道路，4方向 |
| SvgPoint | SvgCoord | SVG 坐标 |
| SkiaPoint | SkiaCoord | Skia 坐标 |
| Point | WPFCoord | WPF 坐标 |
| RoadsId | int[8] | 该道路节点所在道路 ID，8方向，无则等于 -1 |
| NeibourNodesId | int[8] | 该道路节点相邻节点 ID，8方向，无则等于 -1 |
| SameStraightRoadNodesId8Directs | List<int>[8] | 该道路节点所在直线道路在指定方向上节点 ID，8方向，无则等于 null |
| SameStraightRoadNodesId4Directis | List<int>[4] | 该道路节点所在直线道路在指定方向上节点 ID，4方向，无则等于 null |
| IsRoadStartOrEnd | bool | 是否是道路端点 |
| IsStraight | bool | 是否是道路中间点（非端点或路口） |
| IsCross | bool | 是否十字路口 |
| IsTurn | bool | 是否转弯点 |
| IsTShape | bool | 是否丁字路口 |
| IsComplex | bool | 是否复杂路口 |
| Level | int | 道路节点等级 |
| NodeMovingCanMoveDistance | decimal[8] | 该道路节点在 8 方向上各允许移动距离 |
| RoadMovingCanMoveDistance | decimal[8] | 该道路在 8 方向上各允许移动距离 |
| NextNewId（静态） | int | 下一个新道路节点 ID |
| RPGraph | SvgCircle | 在道路预览图里面的几何形态 |

## class Road（道路，从 JSON 加载）

道路基于道路节点而被定义：两个道路节点相连形成的有向线段是道路。

### `JsonProperty` 属性列表

| 属性名 | 类型     | 说明         |
| --- |--------|------------|
| Id | int | 道路 ID      |
| Name | string | 道路名称       |
| NodesId | int[2] | 连成此道路的两个道路节点 ID |
| Nodes | Node[2] | 连成此道路的两个道路节点 |
| StraightRoad | StraightRoad | 该道路所在直线道路 |
| JSONCoordStart | decimal[2] | 道路起点 JSON 坐标 |
| JSONCoordEnd | decimal[2] | 道路终点 JSON 坐标 |
| SvgCoordStart | SvgCoord | 道路起点 SVG 坐标 |
| SvgCoordEnd | SvgCoord | 道路终点 SVG 坐标 |
| SkiaCoordStart | SkiaCoord | 道路起点 Skia 坐标 |
| SkiaCoordEnd | SkiaCoord | 道路终点 Skia 坐标 |
| WPFCoordStart | WPFCoord | 道路起点 WPF 坐标 |
| WPFCoordEnd | WPFCoord | 道路终点 WPF 坐标 |
| Direction | int | 道路方向（0-7） |
| Length | Distance | 道路长度 |
| NexNewId（静态） | int | 下一个新道路 ID |
| StationsId | List<int> | 该道路上的车站列表 |
| CanMoveDirections | int[2] | 允许移动的方向，两个垂直于道路方向的方向 |
| DisplacementWhileMovingTargetNodes | Dictionary<Node, decimal[2]> | 移动该道路时对应道路节点产生的坐标位移 |
| RPGraph | SvgLine | 在道路预览图里面的几何形态 |

## class Station（车站，从 JSON 加载）

车站基于道路而被定义：在道路上定义其位置便形成车站。

### `JsonProperty` 属性列表

| 属性名 | 类型     | 说明         |
| --- |--------|------------|
| Id | int | 车站 ID      |
| Name | string | 车站名称       |
| EnName | string | 车站英文名称       |
| RoadId | int | 车站所在道路 ID |
| OnRoadPos | decimal | 车站在道路上的位置（0-1） |
| Side | string | "left" 或 "right"，表示站名标注在道路前进方向的哪一侧 |
| ConnectsMtr | List<string> | 车站接驳的地铁站名列表 |
| Note | List<string> | 备注，如轮渡、机场、乐园 |

### `JSONIgnore` 属性列表（后期计算）

| 属性名 | 类型     | 说明         |
| --- |--------|------------|
| JSONCoord | decimal[2] | JSON 坐标 |
| SvgCoord | SvgCoord | SVG 坐标 |
| SkiaCoord | SkiaCoord | Skia 坐标 |
| WPFCoord | WPFCoord | WPF 坐标 |
| GeoSide | int | 站名标注相对于站点的8方向位置 |
| RPGraph | SvgCircle | 在道路预览图里面的几何形态 |
| RPText1 | SvgTextSpan | 在道路预览图里的中文站名文本 |
| RPText2 | SvgTextSpan | 在道路预览图里的英文站名文本 |
| RPText | SvgText | 在道路预览图里的站名文本 |
| NextNewId（静态） | int | 下一个新车站 ID |

## class Route（公共汽车线路，从 JSON 加载）

公共汽车线路基于首末站点、经由道路节点和不停靠站点而被定义：一条公共汽车从起点站开往终点站，中间经过一定能连续经过的道路节点（相邻两个经过的道路节点一定是定义某一条道路的两个道路节点），并默认经过沿途道路的所有道路节点，但要跳过指定段道路上的不停靠站点。

### `JsonProperty` 属性列表

| 属性名 | 类型     | 说明         |
| --- |--------|------------|
| Id | int | 线路 ID      |
| Name | string | 线路名称       |
| Color | int[] | 线路色（RGB）       |
| Start | int | 线路起点站 ID       |
| ViaNodes | List<int> | 线路依次经过的道路节点 ID |
| SkipStaions | List<List<int>> | 线路在沿途各段道路上不停靠的站点 ID 列表，长度一定等于 ViaNodes.Count + 1 |
| End | int | 线路终点站 ID       |

## class StraightRoad（直线道路，程序后期加载）

直线道路基于所有已加载的道路而被定义：一组能够相互一直直行可达的道路，组成一条直线道路。

### 属性列表

| 属性名 | 类型     | 说明         |
| --- |--------|------------|
| NodeIds | List<int> | 直线道路上的所有道路节点 ID（未排序）|
| SortedNodeIds | List<int> | 直线道路上的所有道路节点 ID（已排序）|
| Direction | int | 直线道路的方向（0-4）|
| RoadIds | List<int> | 直线道路上的所有道路 ID |
